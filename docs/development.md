# 开发与后续扩展

## 发布约定

功能先在本地累计并验证，记入 CHANGELOG.md“未发布”。用户明确要求时再统一更新版本、构建两个发行包、校验、推送和发布。现有 dist 为已发布版本，本地开发运行 src/Mist.Terminal/bin 下的构建。

## SFTP 分层

- app.js：文件菜单、按会话显示状态、暂停/继续入口。
- MainWindow：原生文件选择、消息分发、会话锁和取消令牌。
- ResumableDownload：续传检查点、偏移读取、完整下载后的落盘，不依赖界面。
- SshSession：SSH/SFTP 连接与服务器身份。

## 当前续传范围

本轮实现单文件下载续传。上传仍为原有的单文件上传，不覆盖远程同名文件。下载暂停、断网或关闭应用时保留目标旁的 `.terminal.part` 和 `.terminal.part.json`；继续使用相同服务器账号、远程文件和本地保存位置。会话内提供继续按钮，应用重启后从文件菜单重新选择原保存位置恢复。

续传核对主机、端口、账号、SSH 指纹、远程路径、大小和修改时间。这不是远程内容的密码学校验；服务器若保留大小和修改时间修改了内容，应另选位置完整下载并核验来源提供的校验和。未完成数据不应被外部编辑。记录不匹配时拒绝拼接，保留原文件和临时数据供用户处理。暂停遇到阻塞网络读取时最多需等待 SFTP 操作超时（30 秒）。不自动重连，不存储额外密码。

## 后续扩展顺序（待用户提出）

1. 上传续传：远端临时文件、源文件指纹、完成后重命名及冲突策略。
2. 传输任务列表：稳定任务 ID、持久任务存储、重连后恢复入口。
3. 队列与并发：独立 SFTP 连接池、单目标互斥、取消和重试策略。
4. 多选、文件夹递归传输、覆盖冲突对话框。

新功能先补充对应协议和真实 SFTP 集成测试，再接入极简界面；不要继续将传输算法堆入窗口代码。
